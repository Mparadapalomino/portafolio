# Portafolio — Marcelo Parada

Sitio personal: desarrollador full-stack, mobile y web. Santa Cruz, Bolivia.

- HTML, CSS y JavaScript sin dependencias ni build.
- Bilingüe (ES/EN), modo claro/oscuro, animaciones con `prefers-reduced-motion`.
- Desplegado en Vercel como sitio estático.

## Formulario de contacto
Para recibir los mensajes por correo, crea una clave gratuita en [Web3Forms](https://web3forms.com)
y pégala en `index.html`:

```js
const FORM_ENDPOINT = "https://api.web3forms.com/submit";
const FORM_KEY = "TU-CLAVE";
```

Sin clave, el formulario prepara el mensaje y ofrece enviarlo por WhatsApp o correo.

## Correr localmente
```bash
npx serve .
```
